# 祭りの射的 — WebXR Shooting Gallery

Three.js と cannon.js で作った一人称視点の「射的」ゲームです。コルク弾6発で、棚の景品を落として得点を競います。
デスクトップではマウスで、WebXR 対応の VR ヘッドセットでも遊べます。静的ファイルだけで動き、ビルドツールは不要です。

## 操作

| 操作 | デスクトップ | VR |
|---|---|---|
| マウスのロック／視点移動 | 画面を一度クリック、マウスを動かす（Esc で解除） | 頭の動き |
| 発射 | 左クリック | トリガー |
| 構える | 右クリック長押し。銃口の先の照星を景品に合わせる | コントローラーを向ける |
| やり直し | R（終了後は銃がロックされ、R を押すまで撃てません） | グリップボタン |

ルール：1ゲーム6発。1発ごとにコルクの装填に 0.8 秒かかります。景品が棚から落ちたら得点です。
画面に照準は出ません。本物の射的のコルク銃と同じく、銃口の先の照星だけが頼りです。

## 技術的なポイント

- **自動補正のない弾道**：コルクは銃身が実際に向いている方向へ飛びます。補正するのは 5.2 m 先での重力による落下だけなので、それ以外の距離では着弾がずれます。
- **難しさは操作感から**：腰だめではランダムな散らばりがあり、銃口は常に手ブレします（構えると小さくなります）。反動で視点が跳ね上がり、毎回装填も必要です。
- **高速物体のすり抜け（tunneling）**：コルクは1回の物理ステップで自身の半径以上動くため、景品をすり抜けてしまいます。コルクの飛行中は物理ステップを 1/480 秒に細かくし、普段は 1/180 秒にしています。
- **多面体の衝突判定**：cannon.js の「球 vs 凸多面体」は高速時に不安定なので、四角錐と三角柱の衝突形状は 6 段に積んだ直方体で近似しています。見た目は正確な多面体のままです。
- **外見と衝突形状の分離**：見た目（`models.js`）は凝ったモデル、衝突（`config.js`）は単純な形状にして、両者の大きさだけを合わせています。
- **手続き的モデリング**：景品も屋台も基本ジオメトリの組み合わせで作り、テクスチャは Canvas で描画しています。外部素材は使っていません。
- **結果判定**：1発ごとの結果は、コルクが止まり、当たった景品がすべて静止してから確定します。落ちた → 獲得、当たったが落ちなかった → 惜しい、何にも当たらなかった → はずれ。スコアボードはイベントが起きたときだけ描き直し、タイマーでは更新しません。
- **マウスボタンの扱い**：右ボタンを押している間は左ボタンの `pointerdown` が発生しないため、`mousedown` / `mouseup` を使っています。
- **WebXR**：コントローラーにも同じ銃モデルを持たせ、デスクトップと VR で発射ロジック（`fire()`）を共有しています。

## プロジェクト構成

```
index.html          ページと依存ライブラリ（three r128、cannon.js 0.6.2。バージョン固定で CDN から読み込み）
css/style.css
js/
  config.js         調整できるパラメーターと景品データ
  state.js          共有ステート
  scene.js          レンダラー、カメラ、物理ワールド
  stall.js          屋台：木目、縞の庇、青海波の幕、提灯、看板、電球、スポットライトと影
  textures.js       Canvas による手続き的テクスチャ（木目、青海波）
  models.js         景品の見た目（箱入りお菓子、招き猫、だるま、くまのぬいぐるみ、ピラミッド箱、三角チョコ箱）
  prizes.js         景品の生成（見た目＋衝突形状）
  gun.js            銃モデルと発射
  game.js           ルール：物理ステップ、得点、1発ごとの結果判定、終了判定、リスタート
  view.js           デスクトップの一人称視点：構え、手ブレ、反動、装填アニメーション
  input.js          マウス／タッチ／キーボード／VR の入力
  board.js          スコアボード（Canvas テクスチャ）
  audio.js          WebAudio で合成した効果音
  main.js           エントリーポイントとメインループ
```

## ローカルで実行

ES modules は `file://` では開けないので、ローカルサーバーが必要です。

```bash
python3 -m http.server 8000     # または npx serve
# http://localhost:8000 を開く
```

## GitHub Pages へのデプロイ

1. このフォルダの中身を GitHub リポジトリに push します（`index.html` はリポジトリ直下に置く）。
2. リポジトリの Settings → Pages → Build and deployment → Source で **Deploy from a branch** を選び、Branch は `main`、フォルダは `/ (root)` にして保存します。
3. 1分ほどで `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開されます。
4. GitHub Pages は HTTPS なので WebXR の条件を満たします。Quest Browser などで URL を開くと「VRに入る」ボタンが表示されます。

## 調整できるパラメーター（`js/config.js`）

| パラメーター | 内容 |
|---|---|
| `HIP_SPREAD` / `ADS_SPREAD` | 腰だめ／構えたときのランダムな散らばり |
| `HIP_SWAY` / `ADS_SWAY` | 腰だめ／構えたときの手ブレの大きさ |
| `COCK` | 1発ごとの装填時間 |
| `SPEED`、`ZERO` | コルクの初速、ゼロイン距離（落下補正の基準） |
| `TYPES`、`LAYOUT` | 景品の質量・得点・配置 |
| `SHADOWS` | 棚のスポットライトの影。VR ヘッドセットで重いときは `false` に |

## 既知の問題と今後

- タッチ操作は簡易対応（タップで発射、長押しで構え）で、終了後にやり直す手段がありません。
- 命中エフェクト、Blender で作ったモデル（現在は手続き的モデリング）、BGM、遠景はまだありません。
- npm + Vite に移行する場合は、three と cannon-es を `import` に切り替えるだけで、他のモジュールはそのまま使えます。
