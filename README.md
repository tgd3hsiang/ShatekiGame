# 祭典射的 — WebXR Shooting Gallery

用 Three.js + cannon.js 做的第一人稱「射的」遊戲：6 發軟木塞，把貨架上的獎品打下來得分。
桌面用滑鼠玩，也支援 WebXR（VR 頭盔手把）。純靜態網頁，不需要打包工具。

## 操作

| 動作 | 桌面 | VR |
|---|---|---|
| 鎖定滑鼠 / 轉視角 | 點一下畫面，移動滑鼠（Esc 解除） | 頭部追蹤 |
| 開槍 | 左鍵 | 扳機 |
| 瞄準 | 右鍵按住，用槍口前端的準星對準獎品 | 直接用手把指向 |
| 重來 | R（只有結算後才會重來，結算後槍會鎖住） | 握把鍵 |

規則：每局 6 發，每發要上膛 0.8 秒。獎品掉出貨架才得分。
畫面上沒有準心，和真正的祭典軟木塞槍一樣只能靠槍口那根準星。

## 技術重點

- **沒有自動瞄準的彈道**：軟木塞沿槍管實際朝向飛出，只預先補償 5.2 公尺處的重力下墜，其他距離會有落差。
- **難度來自手感**：腰射有隨機散布，槍口會持續手晃（瞄準時變小），開槍有後座力與視角上抬，每發需上膛。
- **高速物體穿透（tunneling）**：軟木塞一個物理步會移動超過自己的半徑，會直接穿過獎品。
  軟木塞飛行時把物理步長縮到 1/480 秒，平常用 1/180 秒。
- **多面體碰撞**：cannon.js 的「球 vs 凸多面體」在高速下不穩定，所以四角錐和三角柱的碰撞形狀改用 6 層疊起來的方塊逼近，
  外觀仍用精確的多面體。這是「碰撞形狀與外觀分離」的取捨。
- **結果判定**：每一發的結果在「軟木塞停下、被打到的獎品都靜止」後才確定：
  有掉落 → 得分；碰到但沒掉 → 可惜；完全沒碰到 → 沒打中。計分板只在事件發生時重畫，不靠計時。
- **滑鼠按鍵**：用 `mousedown` / `mouseup` 而不是 `pointerdown`，因為按住右鍵時，左鍵不會再觸發 `pointerdown`。
- **程序化建模**：獎品與攤位全部由基本幾何組合，貼圖用 Canvas 畫，不依賴任何外部素材。外觀（models.js）與碰撞形狀（config.js）分開，外觀可以很細緻，碰撞只用簡單形狀。
- **WebXR**：用同一把槍的模型掛在手把上，桌面與 VR 共用發射邏輯（`fire()`）。

## 專案結構

```
index.html          頁面與依賴(three r128、cannon.js 0.6.2，固定版本從 CDN 載入)
css/style.css
js/
  config.js         所有可調參數與獎品資料
  state.js          共用狀態
  scene.js          渲染器、相機、物理世界、攤位
  prizes.js         獎品生成(外觀 + 碰撞形狀)
  gun.js            槍模型、發射
  models.js         獎品外觀(紙盒零食、招財貓、達摩、絨毛熊、金字塔禮盒、三角巧克力盒)
  stall.js          攤位：木紋、條紋遮雨棚、青海波布幕、紙燈籠、招牌、串燈、聚光燈與陰影
  textures.js       Canvas 程序化貼圖(木紋、青海波)
  game.js           規則：物理步進、得分、結果判定、結算、重來
  view.js           桌面第一人稱視角：瞄準、手晃、後座力、上膛動畫
  input.js          滑鼠 / 觸控 / 鍵盤 / VR 輸入
  board.js          計分板(Canvas 貼圖)
  audio.js          WebAudio 合成音效
  main.js           進入點與主迴圈
```

## 本機執行

ES modules 不能用 `file://` 開啟，需要一個本機伺服器：

```bash
python3 -m http.server 8000     # 或 npx serve
# 開啟 http://localhost:8000
```

## 部署到 GitHub Pages

1. 把這個資料夾的內容推到 GitHub 儲存庫（`index.html` 要在儲存庫根目錄）。
2. 儲存庫 Settings → Pages → Build and deployment → Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，儲存。
3. 約一分鐘後網址會是 `https://<帳號>.github.io/<儲存庫名>/`。
4. GitHub Pages 是 HTTPS，WebXR 需要這個條件。VR 頭盔瀏覽器（例如 Quest Browser）直接開網址，會出現「進入 VR」按鈕。

## 可調參數（`js/config.js`）

| 參數 | 作用 |
|---|---|
| `HIP_SPREAD` / `ADS_SPREAD` | 腰射 / 瞄準的隨機散布 |
| `HIP_SWAY` / `ADS_SWAY` | 腰射 / 瞄準的手晃幅度 |
| `COCK` | 每發上膛時間 |
| `SPEED`、`ZERO` | 軟木塞初速、歸零距離(決定下墜補償) |
| `TYPES`、`LAYOUT` | 獎品的質量、分數、擺放 |
| `SHADOWS` | 貨架聚光燈陰影；VR 頭盔效能不足時改成 `false` |
